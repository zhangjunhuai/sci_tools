# 科研文献中心

个人本地文献管理系统（第一版：文献模块）。为类脑导航方向定制：arXiv 订阅、AI 自动整理、全文 + 语义搜索。

## 启动

```bash
./start.sh          # 默认模式，打开 http://127.0.0.1:8210
./start.sh --dev    # 开发模式（前端热更新，端口 5173）
```

首次运行会自动安装依赖并构建前端。

## 第一版功能

| 模块 | 说明 |
|------|------|
| 文献入库 | 拖拽 PDF → 自动识别 arXiv 号 / DOI（文件名、水印、正文、猜标题多重识别）→ 抓元数据 |
| 链接入库 | 粘贴 arXiv 链接 / ID / DOI 回车直接入库，arXiv 论文自动下载 PDF，DOI 论文自动找 Unpaywall 合法 OA 副本 |
| 浏览器一键入库 | 设置页有书签脚本（拖到书签栏），在订阅期刊的文章页/PDF 页点一下，用浏览器自身登录态抓 PDF 入库 |
| 引文网络 | 每篇文献可查「参考文献 / 被引论文」（Semantic Scholar），按被引量排序，点标题看 AI 速览，可折叠，一键入库（自动下载 arXiv PDF） |
| BibTeX | 文献库勾选多篇或按当前筛选导出 .bib；详情页一键复制单篇 BibTeX |
| Zotero 导入 | 设置页旁「导入 Zotero」上传 CSL JSON（Zotero 里选中条目 → 右键导出，格式选 CSL JSON） |
| 整理 | 项目（研究方向）+ 标签 + 阅读状态 + 星标；配置 API 后入库时 AI 自动打标签 |
| 阅读 | 内嵌 PDF 阅读器：连续滚动翻页 + 虚拟化渲染（长文不卡）；划选文字即弹 AI 中文翻译；四色高亮 |
| 笔记 | 每篇文献一篇 Markdown 笔记，`[[论文标题]]` 双链到库里其他论文 |
| AI 助手 | 结构化摘要；对本文提问；跨文献问答自动检索全库；勾选多篇一键生成 AI 跨文献对比表（方法 / 数据集 / 核心结论 / 局限，2-8 篇） |
| 搜索 | 关键词搜索（含 PDF 全文）+ 语义搜索（自然语言找文献）+「找相似」 |
| arXiv 订阅 | 按分类+关键词抓新论文，AI 按你的研究方向打分排序，一键入库（自动下载 PDF） |

## 首次使用

1. 打开「设置」页，填 API Key（OpenAI 兼容格式：OpenAI / DeepSeek / 兼容中转均可），点「测试连通」。
2. 检查「研究方向」描述是否准确——AI 打标签、摘要、订阅打分都以此为准。
3. arXiv 分类和关键词已预置（q-bio.NC / cs.NE / cs.RO / cs.LG + 网格细胞等关键词），可自行修改。

不配置 API Key 也能用：上传、元数据抓取、全文搜索、高亮、笔记都正常，只是没有 AI 摘要 / 自动标签 / 语义搜索 / 订阅打分。

## 数据与备份

所有数据都在 `backend/data/`：`research.db`（SQLite）+ `pdfs/`（PDF 文件）。备份这个目录 = 备份全部。

## 技术栈

- 后端：Python 3.13 + FastAPI + SQLite（FTS5 全文检索，trigram 分词支持中文）
- 前端：React 18 + Vite + pdfjs-dist
- AI：OpenAI 兼容接口（对话 + embedding），embedding 向量本地暴力检索（个人库规模足够）

## 已知边界（第二版计划解决）

- 「找相似」和语义搜索依赖每篇文献的 embedding，配置 API 后新入库的文献自动计算；旧文献可在重新上传 PDF 或补挂 PDF 时触发
- Zotero CSL JSON 的 PDF 附件按路径匹配，个别附件可能需要手动补传（文献详情页可补挂 PDF）
- 笔记目前是每篇一篇（存在文献上），独立笔记卡片在第二版
