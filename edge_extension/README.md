# 科研划词翻译 · Edge 浏览器扩展

在任意网页选中文字后调用本地「科研文献中心」的 AI 翻译（`/api/ai/translate`，背后是你配置的 OpenAI 兼容接口）。API Key 只存在文献库后端，插件不保存任何密钥。

## 功能

- **划词气泡**：选中文字 → 点旁边的蓝色「译」按钮 → 原地弹出翻译气泡（可复制、ESC 关闭）。
- **右键菜单**：选中文字 → 右键 →「科研划词翻译」。
- **设置页**：配置文献库后端地址（默认 `http://127.0.0.1:8210`），保存时自动做连通检查。

## 安装（Edge 开发者模式加载）

1. 打开 Edge，地址栏输入 `edge://extensions` 回车。
2. 左下角打开「**开发人员模式**」。
3. 点「**加载解压缩的扩展**」，选择本目录（`edge_extension/`）。
4. 工具栏出现蓝色圆形「译」图标即安装成功；建议在工具栏把它固定住。

## 使用前提

- 文献库后端在运行：项目根目录 `./start.sh`（监听 8210）。
- 文献库「设置」页已配置 API Key（翻译由后端调用 AI 完成）。

## 注意

- `host_permissions` 只声明了 `127.0.0.1` / `localhost`，扩展只和本地后端通信；网页选词本身不需要额外权限。
- 后端地址若改了端口，到扩展「设置」页同步修改。
- 想在 Chrome 使用同样步骤（`chrome://extensions` 加载即可，Manifest V3 两边通用）。

## 文件结构

```
edge_extension/
├── manifest.json    # MV3 清单
├── background.js    # 右键菜单 + 调用后端翻译 API
├── content.js/css   # 选词捕获、浮动「译」按钮、翻译气泡
├── popup.html       # 工具栏图标弹窗（使用说明）
├── options.html/js  # 后端地址设置页
└── icons/           # 16/32/48/128 图标
```
